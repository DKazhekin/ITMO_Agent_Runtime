# Базисные агентские функции

В наборе **35 одиночных задач**. Восемь курсовых базисных агентских функций (БАФ) представлены тремя типовыми заданиями и одним собственным вариантом каждая. В отдельной функции Б9 три задания на перенос формулы между ячейками книги Excel. Исходный пример Б1.1 сохранён байт-в-байт. Составные задачи относятся к следующему этапу. [Каталог](../baf/catalog.yaml) · [требования курса к набору](https://github.com/deeppavlov/agentic-course-itmo/blob/818740966b0d5b08fc9e46c3f6e449c824367ba9/projects/A-agent-runtime.md#L112-L164).

| Функция | Типовые задания | Собственный вариант |
|---|---|---|
| Б1. Чтение и извлечение | Порт сервиса, срок оплаты по договору, отсутствующая неустойка | Найти действующий срок уведомления по таблице при наличии старой рассылки |
| Б2. Поиск | Определение функции, 12 чтений переменной в 200 файлах, выбор между одноимёнными функциями | Найти определения на уровне модуля среди одноимённых методов, импортов и комментариев |
| Б3. Создание файла | Конфигурация по схеме, отсортированная таблица, строковые типы значений YAML | Сформировать реестр с идентификаторами, ведущими нулями и типизированным смещением |
| Б4. Редактирование | Строка с версией, переименование функции, правка без смены кодировки | Изменить одно значение в нужной секции и сохранить дубликаты в соседней секции и комментарии |
| Б5. Использование инструмента | Медиана, упавшие тесты, ошибка сборки при выводе `OK` | Взять актуальный счётчик из потока ошибок при наличии устаревшего числа в обычном выводе |
| Б6. Генерация кода | Нормализация строки для адреса, группировка журнала по часам, разность календарных дат | Объединить соприкасающиеся полуинтервалы и отбросить пустые |
| Б7. Рассуждение | Ночная пересадка, наследование ролей с запретами, конфликт правил | Выбрать первый допустимый рейс по времени, вместимости и ограничениям холодовой цепи |
| Б8. Синтез из источников | Продажи из пяти таблиц, решения из десяти протоколов, сравнение регламентов | Свести начальные остатки, проведённые поставки и отгрузки |
| Б9. Перенос формулы | Относительные, закреплённые и смешанные ссылки, адресоподобный текст в кавычках | Отдельная функция из трёх заданий |

## Проверка результата

На каждой попытке запускатель передаёт только условие и содержимое `fixture/`. Файлы независимых проверок, ответы и примеры для самопроверки набора лежат рядом с условием в каталоге задания. Проверка выставляет результат по сохранённым файлам. У заданий Б5 дополнительно проверяется связанная запись вызова команды и её результата, включая стандартный вывод, поток ошибок и код завершения.

Б6 проверяется в отдельном контейнере на основе локального образа `itmo-sandbox:0.1`. Для каждого запуска сеть отключена, файловая система образа доступна только для чтения, рабочие папки и учётные данные хоста не подключаются, время, память и объём вывода ограничены. Код и входные данные передаются контейнеру через стандартный ввод. Ожидаемые ответы остаются у проверяющего процесса.

Б9 открывает сохранённую книгу и сверяет тип и текст целевой формулы. Проверка также сравнивает значения и формулы всех остальных ячеек и порядок листов. Например, в [исходной книге Б9.1](../baf/B9-formula/B9.1-relative/fixture/workbook.xlsx) после копирования `D2` в `D3` ожидается формула `=B3*C3`, исходная `=B2*C2` должна сохраниться. Б9.2 проверяет сдвиг по строке и столбцу при закреплённых и смешанных ссылках. Б9.3 проверяет, что строковые константы `"A1"` и `"B2: keep"` сохраняются. Проверяется перенос формул и контрольных данных в файле, пересчёт значений внешним приложением в оценку не входит.

Команда самопроверки требует установленных зависимостей проекта и доступа к Docker на машине, с которой запускается проверка:

```sh
docker build -f Dockerfile.sandbox -t itmo-sandbox:0.1 .
.venv/bin/python -m baf.validate_tasks
```

[Сохранённый результат](../baf/checker-validation.json) содержит 35 принятых правильных решений, 35 отклонённых незавершённых состояний, 35 отклонённых правдоподобных ошибок и три дополнительные проверки первого этапа. В этот результат входят проверки файлов задания без обращений к модели.

## Прогоны

Для девяти коротких воспроизводимых проверок записанных действий нужен запущенный сервис в режиме `mock`:

```sh
.venv/bin/python -m baf.run --mode mock
```

Команда ниже назначает все 35 попыток на первой паре «последовательный управляющий цикл + DeepSeek V4.1 Flash 1017». В режиме `real` каждая попытка использует новую смонтированную синтетическую папку на Mac. Сведения о модели, подключение Mac и общий предел расходов настраиваются перед запуском. [Настройка модели и учёт расходов](reference/model.md).

```sh
.venv/bin/python -m baf.run --mode real --model-evidence .local/model-evidence.json
```

`--task B9.1` выбирает отдельную задачу, опцию можно повторять. `--workspace mounted` включает монтирование и для пробного запуска в режиме `mock`. Для Б6 указывается нужный локальный контекст Docker через `DOCKER_CONTEXT`, если он отличается от активного.

В каталоге попытки сохраняются `manifest.json` с парой, назначенными задачами и контрольными суммами исходников, `results.jsonl` с результатами по мере завершения и `summary.json` с числами назначенных, начатых и зачтённых задач по каждой функции. В папке каждой задачи лежат окончательные файлы, события `trace.jsonl` и отдельная оценка `result.json` с причиной, временем и числами входных и выходных токенов. `null` означает, что полный учёт соответствующего показателя недоступен. Сумма известных расходов указывается отдельно от полного итога. Суммы по вызовам берутся из поля `usage.cost`, подтверждённого посредником и округлённого до миллионной доли доллара США. [Источник расчёта OpenRouter](https://openrouter.ai/docs/cookbook/administration/usage-accounting).

Команда ниже собирает публикуемую копию всех попыток. В итог по 35 уникальным задачам входит первый зарегистрированный исход каждой задачи. Повторы остаются отдельными записями с файлами и событиями. Полный расход записывается только при полном учёте, известные начисления из ответов перечисляются отдельно от необработанных данных поставщика и общего журнала бюджета.

```sh
.venv/bin/python -m baf.report --source results/checkpoint-2/baf/real --output evidence/checkpoint-2/baf
```

[Сводка попыток второй точки](../evidence/checkpoint-2/baf/report.json).

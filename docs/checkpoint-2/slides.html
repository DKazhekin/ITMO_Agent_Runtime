В проверке окна с заранее заданными ответами модели на Mac появился answer.txt со значением 8137. События вернулись в окно через шлюз.

Какие данные передаются и у кого есть доступ
Клиент ⇄ шлюз
Запросы и отмена передаются сообщениями JSON по протоколу HTTP. События поступают от сервера потоком (SSE). После обрыва клиент запрашивает события с последнего полученного номера.
Цикл ⇄ менеджер песочниц
Цикл отправляет имя инструмента и параметры. Менеджер возвращает код завершения, вывод и итог записи. Доступ к службе контейнеров есть у менеджера.
Помощник Linux ⇄ файловая служба Mac
Mac открывает защищённый туннель (SSH). Внутри него передаются файловые операции (SFTP). Помощник подключает папку к Linux как файловую систему (SSHFS), доступную в песочнице под именем /work.
Посредник ⇄ внешний поставщик
Посредник отправляет контекст по защищённому соединению (HTTPS) в OpenRouter. Ключ и журнал расходов остаются у посредника. У песочницы нет сетевого доступа.

Что происходит, если человек меняет файл

Mac открывает защищённое соединение. Благодаря монтированию программа в Linux видит выбранную папку по пути /work.

В задаче Б9.1 нужно скопировать формулу из D2 в пустую ячейку D3. При копировании на строку вниз ссылки на множители тоже должны сдвинуться.

  1. Песочница изменила книгуКоманда записала формулу и завершилась с кодом 0.
  2. Клиент на Mac сохранил файлВ журнале появилось подтверждение записи книги.
  3. Проверка открыла книгу сноваВ D3 оказалась нужная формула. Исходная формула и контрольные ячейки сохранились.

Весь пример занял 1,421 с. Ответы модели задали заранее. Команда отработала в песочнице, а проверка прочитала файл с Mac. Расход внешних токенов — 0.

Почему остановились перед Б6

Посредник второй раз не смог подтвердить модель или поставщика и остановил новые обращения. Б6–Б9 остались без платных попыток.

Причины семи неудач. Трижды истекло время ожидания. Для двух ошибок обращения к сервису журнал не сохранил подробности. Ещё в двух задачах не подтвердилась запись файла.

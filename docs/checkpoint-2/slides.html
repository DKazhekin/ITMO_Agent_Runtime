Монтирование и сохранение

Mac открывает туннель. Linux подключает рабочую папку в /work и проверяет, что поколение монтирования живо.

1. ПесочницаЧитает файл или вызывает запись через /work.
2. Помощник LinuxПроверяет подтверждённые операции SFTP и связывает их с вызовом инструмента.
3. MacСверяет черновик, версию и право на публикацию. Возвращает квитанцию.

Подтверждённая запись

Новый файл создаётся, если имя свободно. Существующий файл заменяется в согласованном режиме macOS при совпадении версии.

Остановка при сбое

После обрыва важно установить, успела ли запись попасть в исходную папку.

Потеря монтирования

  • До операции — mount_lost.
  • Во время записи без квитанции — write_outcome_unknown.
  • Для следующего запуска открывается новая сессия. Старая запись автоматически не повторяется.

Отмена и очистка

  • Клиент посылает отмену по номеру запуска.
  • Менеджер удаляет контейнер и процессы, помощник снимает монтирование.
  • Технический итог остаётся в журнале. При гонке записывается один финальный result.

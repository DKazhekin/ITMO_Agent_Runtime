# Half-open intervals
merge_ranges(ranges: list[list[int]]) -> list[list[int]] принимает границы интервалов [start, end) в произвольном порядке. Если start > end, выброси ValueError. Пустые интервалы [x, x) убери. Пересекающиеся и соприкасающиеся интервалы объединяй. Результат верни как список двухэлементных списков, отсортированных по началу. Исходный список не меняй.

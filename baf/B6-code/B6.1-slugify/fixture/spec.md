# URL slug
Реализуй slugify(text: str) -> str. Примени нормализацию Unicode NFKD, убери комбинируемые знаки и приведи текст к нижнему регистру. Замени каждую группу символов вне ASCII a-z и 0-9 одним дефисом. Убери дефисы с краёв. Если допустимых символов не осталось, верни пустую строку.
Пример: '  Crème BRÛLÉE! ' → 'creme-brulee'.

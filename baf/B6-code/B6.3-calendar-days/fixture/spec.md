# Calendar day difference
Функция days_between(a: str, b: str) возвращает число календарных дней от a до b со знаком (b минус a). Поддержи только строгий формат YYYY-MM-DD либо тот же формат с символом U+2212 «−» вместо обоих дефисов. Допустимы только цифры ASCII, пробелы по краям можно убрать. Смешение дефисов, пустая строка и невозможная дата должны вызвать ValueError.

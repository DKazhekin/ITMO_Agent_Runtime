# Hourly log aggregation
Функция aggregate(lines: list[str]) возвращает словарь {час_UTC: сумма_байт}. Запись: 'YYYY-MM-DDTHH:MM:SS±HH:MM LEVEL BYTES' или то же с Z вместо смещения. Поля разделены пробельными символами, BYTES — неотрицательное целое из ASCII цифр, LEVEL — INFO, WARN или ERROR. Принимай только такие строки с календарно корректной датой и валидным смещением. Пропускай пустые и неверные строки. Приводи время к UTC до группировки. Ключи в формате YYYY-MM-DDTHH:00Z, учитывай все три уровня. Пустой набор даёт {}.

# Результаты второй контрольной точки

Все файлы заданий в этих примерах синтетические. Время отдельной попытки включает работу клиента и программной проверки. В событиях зафиксированы отдельные интервалы работы сервера и инструмента. Манифесты содержат отпечатки исходников, с которыми запускалась попытка.

**DeepSeek прошла 9 из 12 начатых задач. Из 35 назначенных 23 остались без попытки.** По группам получены 4/4 для Б1, 3/4 для Б2 и 2/4 для Б3. Б2.3 и Б3.3 завершились по тайм-ауту связи. На Б3.4 посредник не смог подтвердить закреплённые модель и поставщика. Журнал заблокировал новые платные запросы. При проверке в 14:52 МСК счётчик OpenRouter увеличился на 0,005523127 доллара. Посредник записал 0,005548 доллара с округлением по каждому запросу и удерживал ещё 0,70 доллара в резерве. [Первые исходы, события и пропуски](baf/report.json) · [Учёт расходов](budget.json) · [Параметры модели](model-profile.json).

Программы для воспроизведения включают [полный набор задач](../../baf/run.py), [локальные проверки](../../scripts/check.sh) и [измерение операций](../../scripts/measure_mounted.py). Пара для модельной оценки использует последовательный управляющий цикл и DeepSeek V4.1 Flash 1017 в режиме `high` через DeepInfra FP8. Лимит всего эксперимента составляет 6 долларов США. Служба расходов резервирует сумму до запроса и сохраняет учёт между перезапусками. Результаты первой точки относятся к отдельному набору из 15 задач.
